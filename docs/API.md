# Elets SalesCall AI — API Reference (v1)

Base URL: `{API_BASE_URL}/api/v1` · JSON, snake_case · timestamps ISO-8601 UTC · IDs are UUID strings.
Interactive docs (generated by FastAPI): `/docs` (Swagger) and `/redoc`.

Auth: `Authorization: Bearer <access_token>` on every endpoint except `/auth/login`, `/auth/refresh`,
`/health`, signed recording/export URLs, and provider webhooks.

Errors: `{"detail": "<message>", "code": "<machine_code>", ...extra}` with an HTTP status.
Common codes: `not_found`, `forbidden`, `validation_error`, `duplicate_lead`, `telephony_not_configured`,
`telephony_error`, `lead_busy`, `opted_out`, `outside_calling_hours`, `consent_required`, `llm_not_configured`.

Paginated responses: `{"items": [...], "total": 120, "page": 1, "page_size": 20}` (`page` starts at 1, `page_size` ≤ 100).

Date range params (analytics and lists): `range=today|yesterday|this_week|this_month|custom` with
`from=YYYY-MM-DD&to=YYYY-MM-DD` for `custom`. Ranges are evaluated in the org timezone (default Asia/Kolkata).

Roles: `admin`, `manager`, `executive`. Scope: executive → own data, manager → own team, admin → all.

## Leads

| Method | Path | Notes |
|---|---|---|
| GET | `/leads?q=&status=&priority=&assigned_to=&source=&industry=&favourites=&followup_due=&page=&page_size=&sort=` | `Page<Lead>`; `q` matches name/company/email/designation, or an exact phone number; `sort` = `-created_at` (default), `next_followup_at`, `-last_called_at`, `full_name`, `-priority`; `assigned_to=me` and `assigned_to=unassigned` are accepted |
| POST | `/leads` | `LeadCreate` → `Lead`. `409 duplicate_lead` with `duplicate_lead_id` when phone or email exists |
| POST | `/leads/check-duplicate` | `{phone?, email?}` → `{duplicate, lead_id, matched_on}` |
| GET | `/leads/lookup?phone=` | `Lead` or `404` (dialer number lookup) |
| GET | `/leads/{id}` | `Lead` |
| PATCH | `/leads/{id}` | partial `LeadCreate` + `status?`, `assigned_to_id?` (manager/admin) |
| DELETE | `/leads/{id}` | admin only, `204` |
| GET | `/leads/{id}/timeline` | `[TimelineItem]` newest first |
| GET | `/leads/{id}/calls` | `[UnifiedCall]` (human and AI calls for this lead) — `{id, origin: human|ai, direction, lead_id, lead_name, salesperson_id, salesperson_name, ai_agent_id, agent_name, campaign_id, campaign_name, provider, status, started_at, answered_at, ended_at, duration_seconds, outcome, interest_level, summary}` |
| POST | `/leads/{id}/favourite` / DELETE | `204` |
| POST | `/leads/{id}/opt-out` | `{reason?}` → `Lead` (blocks all future calls to this number) |
| POST | `/leads/assign` | manager/admin: `{lead_ids: [...], assignee_id}` → `{assigned}` |
| POST | `/leads/import` | manager/admin, multipart `file` (.csv/.xlsx), optional form field `assignee_id`, `source` → `ImportResult` |
| GET | `/leads/import/template` | CSV template download |

`LeadCreate`: `{full_name, company_name?, phone, alternate_phone?, email?, designation?, industry?, location?, source?, priority: low|medium|high, remarks?, assigned_to_id?, consent_status?: unknown|granted|revoked}`

`Lead`: `{id, full_name, company_name, phone, phone_masked, alternate_phone, email, designation, industry, location, source, assigned_to_id, assigned_to_name, status, priority, last_called_at, next_followup_at, remarks, consent_status, opted_out, is_favourite, call_count, created_at, updated_at}`
— `phone`/`alternate_phone` are masked for executives when `mask_numbers_for_executives` is on.

Lead statuses: `new, assigned, contacted, interested, follow_up, meeting_scheduled, converted, lost`.

`TimelineItem`: `{id, type: created|assigned|status_changed|human_call|ai_call|note|followup|handoff|opt_out|imported, at, title, description, actor_name, ref_id}`

`ImportResult`: `{total_rows, created, duplicates, errors: [{row, error}], lead_ids: [...]}`
Recognised columns (case-insensitive, aliases in brackets): full_name [name], company_name [company],
phone [mobile, phone_number], alternate_phone, email, designation [title], industry, location [city],
source [lead_source], priority, remarks [notes].

## Human calls (dialer)

| Method | Path | Notes |
|---|---|---|
| POST | `/calls` | `{lead_id?, phone_number?}` (one required) → `201 HumanCall` with `status: initiated` and a `provider_call_id` once the provider accepted the request. Failures: `503 telephony_not_configured`, `502 telephony_error`, `409 lead_busy`, `403 opted_out`, `403 outside_calling_hours`, `422` missing calling number. Errors include `call_id` when a failed row was recorded |
| GET | `/calls?salesperson_id=&lead_id=&status=&outcome=&direction=&range=&from=&to=&page=` | `Page<HumanCall>` scoped by role |
| GET | `/calls/active` | `HumanCall` or `null` for the current user |
| GET | `/calls/recent?limit=20` | `[HumanCall]` current user's recent calls |
| GET | `/calls/{id}` | `HumanCall` with `notes` |
| POST | `/calls/{id}/hangup` | asks the provider to end the call → `HumanCall` |
| POST | `/calls/{id}/disposition` | `{outcome, notes?, followup_at?, lead_status?}` → `HumanCall` |
| POST | `/calls/{id}/notes` | `{body}` → `CallNote` |

`HumanCall`: `{id, direction: outbound|inbound, lead_id, lead_name, phone_number, salesperson_id, salesperson_name, provider, provider_call_id, status, started_at, answered_at, ended_at, duration_seconds, talk_seconds, recording_id, outcome, followup_at, failure_reason, notes: [CallNote], created_at}`

Statuses: `initiated, ringing, connected, completed, busy, not_answered, failed, rejected`.
Outcomes: `interested, not_interested, follow_up_required, meeting_scheduled, converted, wrong_number, no_response`.

`CallNote`: `{id, body, author_id, author_name, created_at}`

`DashboardStats`: `{scope: personal|team|organization, total_leads, total_calls, successful_calls, missed_calls, connected_calls, not_connected, total_duration_seconds, pending_followups, leads_converted, ai_calls, ai_successful_conversations}`

`LeaderboardRow`: `{user_id, name, team_name, calls, connected, duration_seconds, conversions}`

`ChannelStats`: `{calls, connected, avg_duration_seconds, interested, converted, qualified}`

`MyStats`: `{calls_today, calls_this_week, calls_this_month, connected, missed, avg_duration_seconds, interested, converted, followups_pending}`

Definitions: **connected** = answered calls; **not connected** = outbound busy / not answered / failed / rejected;
**missed** = inbound calls not answered; **successful** = connected human calls whose outcome is interested,
follow-up required, meeting scheduled or converted; **AI successful conversation** = connected AI call with
interest level high/medium or a qualification score ≥ 60.

## WebSocket — `/api/v1/ws?token=<access_token>`

Server → client messages: `{"type": "<event>", "data": {...}}`

| type | data |
|---|---|
| `hello` | `{user_id}` |
| `call.status` | `HumanCall` (sent to the salesperson, their manager and admins) |
| `call.incoming` | `HumanCall` (inbound call routed to this user) |
| `ai_call.status` | `AICall` (admins/managers) |
| `campaign.progress` | `{campaign_id, status, stats}` |
| `notification` | `Notification` |

Client → server: `{"type": "ping"}` → `{"type": "pong"}`.

## Provider callbacks (not called by the app)

| Path | Purpose |
|---|---|
| `POST /webhooks/telephony/{provider}/status?kind=human|ai&cid=&wt=` | call status callbacks |
| `POST /webhooks/telephony/{provider}/recording?kind=&cid=&wt=` | recording ready |
| `GET|POST /webhooks/telephony/{provider}/answer?kind=&cid=&wt=` | call-flow XML (Twilio TwiML / Plivo XML) |
| `POST /webhooks/telephony/{provider}/inbound` | inbound call routing |
| `GET /webhooks/telephony/exotel/voicebot-url?cid=&wt=` | Exotel Voicebot dynamic WSS URL |
| `WS /media/{provider}/{ai_call_id}?wt=` | bidirectional audio for AI calls |

`wt` is an HMAC of `kind:cid` with `WEBHOOK_SIGNING_SECRET`; requests with a bad token are rejected.
